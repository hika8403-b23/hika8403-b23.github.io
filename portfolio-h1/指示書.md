# ポートフォリオサイト 要件定義書

## 1. プロジェクト概要
職業訓練校での学習成果をまとめたポートフォリオWebサイトを構築する。
企業の採用担当者をターゲットとし、制作スキルや思考プロセス（制作目的・工夫点など）を効果的に伝えることを目的とする。

* **コーディング方針:** GitHub Copilotを活用して実装を行うため、標準的で可読性の高いコード構造と明確なクラス命名（BEM等）を採用する。

---

## 2. サイト構成（3階層構造）
サイト全体は以下の3階層で構成する。

1. **第1階層：トップページ (`index.html`)**
   * オープニング演出（左右開閉式カーテンアニメーション）
   * メインビジュアル
   * 自己紹介・スキルセット一覧
   * 制作作品（ポートフォリオ）のサムネイル一覧
   * コンタクト情報（またはフッター）
2. **第2階層：作品詳細ページ (`works/work-01.html` など)**
   * 作品のタイトル・メイン画像
   * 制作の目的・ターゲット・課題解決のアプローチ
   * 担当範囲・制作期間・使用ツール・技術スタック
   * デザインや実装における工夫点
   * **第3階層（実際の作品ページ）への遷移ボタン**
   * トップページへ戻る導線
3. **第3階層：各作品のページ (`works/work-01/index.html` または外部URL)**
   * 実際に制作したWebサイトやアプリケーションの本体。

---

## 3. 機能・演出要件

### 3.1 オープニング演出（左右開閉式カーテンアニメーション）
トップページ（`index.html`）への初回アクセス時に、以下の構造と流れでオープニング演出を行う。

* **HTML構造（画面構成）:**
  * 画面全体を覆う親コンテナ（例：`.opening-curtain`、`position: fixed; inset: 0; z-index: 9999;`）を最前面に配置する。
  * その内部に、画面を左右に2分割する **左カーテン要素（`.curtain-left`）** と **右カーテン要素（`.curtain-right`）** を横並び（幅 `50%` ずつ、高さ `100%`）で配置する。
  * カーテンの前面中央（`position: absolute` で上下左右中央配置）に、**GIFアニメーション画像（`opening.gif`）** を配置する。
* **アニメーションの流れ（タイムライン目安：全体 約3.5秒）:**
  1. **0.0秒〜2.0秒（GIF再生）:** 左右のカーテンは閉じた状態で、中央のGIFアニメーションが再生される。
  2. **2.0秒〜2.5秒（GIFフェードアウト）:** GIFアニメーションが `@keyframes` によりフェードアウト（`opacity: 1` → `0`）する。
  3. **2.3秒〜3.5秒（カーテン左右開閉）:** GIFの消失と入れ替わるように、左カーテンは左方向へ（`transform: translateX(-100%)`）、右カーテンは右方向へ（`transform: translateX(100%)`）スライドアウトする `@keyframes` アニメーションを実行し、背面のトップページを現す。
* **完了後の処理:**
  * カーテンの開閉アニメーション終了後（`animationend` イベント検知）、親コンテナ（`.opening-curtain`）に非表示用クラスを付与（`display: none` または `pointer-events: none; visibility: hidden;`）し、トップページの操作やスクロールを可能にする。
  * アニメーション再生中は背面のスクロールを禁止（`overflow: hidden`）にする。
* **UXへの配慮（重要）:**
  * 作品詳細ページからトップページへ戻った際、毎回アニメーションが再生されるとストレスになるため、`sessionStorage` を使用し、**同一セッション内での2回目以降のアクセス時はカーテンを即座に非表示にしてトップページを表示する**制御をJavaScriptで実装する。
  * ユーザーが演出を飛ばしたい場合を想定し、クリックで即座にスキップできる機能も実装する。

### 3.2 ナビゲーション・ページ遷移
* ヘッダーメニュー（About, Skills, Worksなど）からのスムーズスクロール。
* 作品詳細ページからトップページの「Works」セクションへスムーズに戻れるアンカーリンクの設置。

### 3.3 レスポンシブ対応
* PC（1024px以上）、タブレット（768px〜1023px）、スマートフォン（767px以下）の各デバイスでレイアウトが崩れないよう、レスポンシブWebデザインを適用する。

## 4. 技術スタック・ディレクトリ構成

### 4.1 使用技術
* **HTML5:** セマンティックなマークアップ
* **CSS3:** Flexbox / CSS Grid、CSS Variables（カスタムプロパティ）、`@keyframes` アニメーション、`transform: translateX()`
* **JavaScript (ES6+):** DOM操作、アニメーション終了検知（`animationend` イベント）、`sessionStorage` による表示制御

### 4.2 推奨ディレクトリ構成
GitHub Copilotがファイルパスを推測しやすいよう、以下の構成を基本とする。

```text
portfolio-root/
├── index.html              # 第1階層：トップページ
├── assets/
│   ├── css/
│   │   ├── reset.css       # リセットCSS
│   │   └── style.css       # 共通・各ページスタイル
│   ├── js/
│   │   └── main.js         # カーテン制御・スクロール制御
│   └── images/
│       ├── opening.gif     # オープニング用GIFアニメーション
│       └── works/          # 作品サムネイル・キャプチャ画像
└── works/                  # 第2階層：作品詳細ページ群
    ├── work-01.html        # 作品1の詳細ページ
    ├── work-02.html        # 作品2の詳細ページ
    └── work-03.html        # 作品3の詳細ページ
    # ※第3階層の実際の作品は別ディレクトリまたは外部リンク（GitHub Pages等）として配置
```

## 5. GitHub Copilot への実装指示プロンプト例
コーディングを進める際は、各ファイル（`index.html`, `style.css`, `main.js`）を開いた状態で、Copilot Chatに以下のように指示を出すとスムーズです。

* **HTML作成時:**
  > 「`要件定義.md` の構成に基づき、トップページ（`index.html`）のHTML構造を作成してください。最上部に左右開閉式のカーテンオーバーレイ（`.opening-curtain` の中に `.curtain-left`、`.curtain-right`、中央配置の `opening.gif`）を配置し、その下にヘッダー、メインビジュアル、自己紹介、スキル一覧、作品一覧、フッターを配置してください。」
* **CSS作成時:**
  > 「`要件定義.md` の3.1に基づき、左右開閉式カーテンのCSSを実装してください。最初は画面を覆い、2秒後に中央のGIFがフェードアウトし、続いて左カーテンが `translateX(-100%)`、右カーテンが `translateX(100%)` で左右に開く `@keyframes` アニメーションを作成してください。」
* **JS作成時:**
  > 「`要件定義.md` に基づき `main.js` を作成してください。`sessionStorage` を確認し、初回訪問時のみカーテンアニメーションを再生して終了後に非表示にしてください。また、クリックでのスキップ機能と、2回目以降の訪問時は最初からカーテンを非表示にする処理も実装してください。」
