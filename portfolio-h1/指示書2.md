# ポートフォリオサイト 要件定義書

## 1. プロジェクト概要
職業訓練校での学習成果をまとめたポートフォリオWebサイトを構築する。
企業の採用担当者をターゲットとし、制作スキルや思考プロセス（制作目的・工夫点など）を効果的に伝えることを目的とする。

* **コーディング方針:** GitHub Copilotを活用して実装を行うため、標準的で可読性の高いコード構造と明確なクラス命名（BEM等）を採用する。

---

## 2. サイト構成（3階層構造）
サイト全体は以下の3階層で構成する。

1. **第1階層：トップページ (`index.html`)**
   * オープニング演出（左右開閉式カーテンアニメーション）
   * メインビジュアル
   * 自己紹介・スキルセット一覧
   * 制作作品（ポートフォリオ）のサムネイル一覧
   * コンタクト情報（またはフッター）
2. **第2階層：作品詳細ページ (`works/work-01.html` など)**
   * 作品のタイトル・メイン画像
   * 制作の目的・ターゲット・課題解決のアプローチ
   * 担当範囲・制作期間・使用ツール・技術スタック
   * デザインや実装における工夫点
   * **第3階層（実際の作品ページ）への遷移ボタン**
   * トップページへ戻る導線
3. **第3階層：各作品のページ (`works/work-01/index.html` または外部URL)**
   * 実際に制作したWebサイトやアプリケーションの本体。

---

## 3. 機能・演出要件

### 3.1 オープニング演出（左右開閉式カーテンアニメーション）
トップページ（`index.html`）への初回アクセス時に、以下の構造と流れでオープニング演出を行う。

* **HTML構造（画面構成）:**
  * 画面全体を覆う親コンテナ（例：`.opening-curtain`、`position: fixed; inset: 0; z-index: 9999;`）を最前面に配置する。
  * その内部に、画面を左右に2分割する **左カーテン要素（`.curtain-left`）** と **右カーテン要素（`.curtain-right`）** を横並び（幅 `50%` ずつ、高さ `100%`）で配置する。
  * カーテンの前面中央（`position: absolute` で上下左右中央配置）に、**GIFアニメーション画像（`images/opening.gif`）** を配置する。
* **アニメーションの流れ（タイムライン目安：全体 約3.5秒）:**
  1. **0.0秒〜2.0秒（GIF再生）:** 左右のカーテンは閉じた状態で、中央のGIFアニメーションが再生される。
  2. **2.0秒〜2.5秒（GIFフェードアウト）:** GIFアニメーションが `@keyframes` によりフェードアウト（`opacity: 1` → `0`）する。
  3. **2.3秒〜3.5秒（カーテン左右開閉）:** GIFの消失と入れ替わるように、左カーテンは左方向へ（`transform: translateX(-100%)`）、右カーテンは右方向へ（`transform: translateX(100%)`）スライドアウトする `@keyframes` アニメーションを実行し、背面のトップページを現す。
* **完了後の処理:**
  * カーテンの開閉アニメーション終了後（`animationend` イベント検知）、親コンテナ（`.opening-curtain`）に非表示用クラスまたは `hidden` 属性を付与し、`.opening-curtain[hidden] { display: none; }` 等で確実に非表示にしてトップページの操作やスクロールを可能にする。
  * アニメーション再生中は背面のスクロールを禁止（`overflow: hidden`）にする。
* **UXへの配慮（重要）:**
  * 作品詳細ページからトップページへ戻った際、毎回アニメーションが再生されるとストレスになるため、`sessionStorage` を使用し、**同一セッション内での2回目以降のアクセス時はカーテンを即座に非表示にしてトップページを表示する**制御をJavaScriptで実装する（初回描画時のチラつき防止のため、`<head>` 内での判定も併用する）。
  * ユーザーが演出を飛ばしたい場合を想定し、クリックで即座にスキップできる機能も実装する。

### 3.2 ナビゲーション・ページ遷移
* ヘッダーメニュー（About, Skills, Worksなど）からのスムーズスクロール。
* 作品詳細ページからトップページの「Works」セクションへスムーズに戻れるアンカーリンクの設置。

## 4. デザイン・CSS仕様

### 4.1 フォント設定
* Google Fonts から以下の2種類のフォントを `index.html`（および各HTMLファイル）の `<head>` 内で読み込み適用すること。
  * 欧文フォント: **Montserrat**
  * 和文フォント: **Noto Sans Japanese** (`Noto Sans JP`)
  ※未指定・空欄の場合はテーマに最適な組み合わせをAIが自動選定すること。

### 4.2 CSSカスタムプロパティ（`:root` 定義）
* `css/style.css` 冒頭の `:root` に以下の基本変数を定義し、説明コメントを付与すること。
  * `--font_en`: 欧文フォント指定（例: `'Montserrat', sans-serif`）
  * `--font_ja`: 和文フォント指定（例: `'Noto Sans JP', sans-serif`）
  * `--font-family`: `var(--font_en), var(--font_ja)`
  * `--primary-color`: メインカラー
  * `--secondary-color`: サブカラー
  * `--bg-color`: 背景色
  * `--text-color`: 基本文字色

### 4.3 【配色完全変数化ルール】
* `css/style.css` 内のすべての配色指定（背景色・文字色・ボタン・ホバー時・枠線・影等）に**直接のカラーコード（`#xxxxxx` や `rgb(...)` 等）を記述することは一切厳禁**とする。
* AIが追加で差し色や装飾用カラー（カーテンの背景色や影の色を含む）を使用したい場合は、必ず `:root` 内に新しいCSS変数（例: `--accent-color`, `--border-color`, `--hover-color`, `--curtain-bg-color`, `--shadow-color` 等）を追加定義し、常に `var(...)` 経由で適用すること。

### 4.4 レスポンシブ対応・マイクロインタラクション
* スマホ表示対応（`@media (max-width: 768px)`）のレスポンシブCSSも併せて出力すること。
* ボタンのホバーアニメーション、カードの浮き上がり（`transform: translateY(...)`）、FAQアコーディオンアニメーション（該当セクションがある場合）はAI側で自動実装すること。

## 5. 技術スタック・ディレクトリ構成

### 5.1 使用技術
* **HTML5:** セマンティックなマークアップ
* **CSS3:** Flexbox / CSS Grid、CSS Variables（カスタムプロパティ）、`@keyframes` アニメーション、`transform`
* **JavaScript (ES6+):** DOM操作、アニメーション終了検知（`animationend` イベント）、`sessionStorage` による表示制御

### 5.2 ディレクトリ構成
ルートフォルダ直下に `index.html`、`css/`、`js/`、`images/`、`works/` を配置するシンプルな構成を採用する。

```text
portfolio-root/
├── index.html              # 第1階層：トップページ
├── css/
│   └── style.css           # 共通・各ページスタイル（リセットスタイル含む）
├── js/
│   └── script.js           # カーテン制御・スクロール制御
├── images/
│   ├── opening.gif         # オープニング用GIFアニメーション
│   └── works/              # 作品サムネイル・キャプチャ画像
└── works/                  # 第2階層：作品詳細ページ群
    ├── work-01.html        # 作品1の詳細ページ
    ├── work-02.html        # 作品2の詳細ページ
    └── work-03.html        # 作品3の詳細ページ
    # ※第3階層の実際の作品は別ディレクトリまたは外部リンク（GitHub Pages等）として配置
```

## 6. GitHub Copilot への実装指示プロンプト例
既存のファイル構成を今回のディレクトリ構成（`css/style.css`, `js/script.js`）および「4. デザイン・CSS仕様」に合わせて更新する際は、Copilot Chatに以下のように指示を出すとスムーズです。

* **HTML更新時:**
  > 「`指示書2.md` の 4.1 と 5.2 に基づき、`index.html` を更新してください。`<head>` 内に Google Fonts（Montserrat と Noto Sans JP）を読み込む `<link>` タグを追加し、CSSの読み込み先を `css/style.css`、JSの読み込み先を `js/script.js`、画像パスを `images/...` に変更してください。」
* **CSS更新・追記時:**
  > 「`指示書2.md` の 4.2〜4.4 に基づき、`css/style.css` を更新してください。冒頭の `:root` にフォント変数と配色変数を定義し、既存のカーテンCSS内のカラーコード（`#1c1c24` や `#fff` など）も含めてすべての色を `var(...)` に置き換えてください。あわせて、ヘッダー・Hero・About・Skills・Works・フッターのレイアウト、ボタンホバーやカードの浮き上がりアニメーション、`@media (max-width: 768px)` のレスポンシブ対応CSSも実装してください。」
