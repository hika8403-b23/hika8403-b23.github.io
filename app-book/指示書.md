# アプリ開発指示書：本の検索＆読書記録・積読管理アプリ

## 1. プロジェクト概要
* **アプリ名（仮）:** Tsundoku Shelf（ツンドクシェルフ） / 読書記録・積読管理アプリ
* **目的:** 書籍を検索してマイ本棚に登録し、「積読」「読書中」「読了」のステータス管理・感想メモ・読書統計を行えるWebアプリケーションを作成する。
* **ターゲットユーザー:** 本を買うものの積読が増えがちな人、読書履歴や感想を手軽に整理したい人。
* **使用技術:**
  * HTML / JavaScript（または React / Vue など授業で使用するフレームワーク）
  * CSSフレームワーク: **Tailwind CSS**
  * 外部API: **Google Books API (Volumes API)**
  * データ保存: **localStorage**（または授業で使用するDB）

---

## 2. 機能要件

### 2.1 書籍検索機能（Google Books API連携）
* キーワード入力による書籍検索機能。
* 検索対象フィルターの切り替え機能：
  * すべて（通常検索）
  * タイトル（クエリに `intitle:` を付与）
  * 著者（クエリに `inauthor:` を付与）
  * ISBN（クエリに `isbn:` を付与）
* 検索結果の一覧表示（表紙画像、タイトル、著者名、出版日）。
* **マイ本棚への登録機能:**
  * 各書籍カードに「＋ 積読に追加」ボタンを配置する。
  * すでにマイ本棚に登録済みの書籍（`id` が一致するもの）は「登録済み」バッジを表示し、重複登録を防止する。

### 2.2 マイ本棚・読書記録管理機能（CRUD）
* **ステータス別フィルタリング（タブ切り替え）:**
  * `すべて` / `積読（読みたい）` / `読書中` / `読了`
  * 各タブに該当する書籍の件数をバッジ表示する。
* **本棚内検索・並び替え:**
  * タイトル・著者名での絞り込み検索。
  * 並び替え（追加日新しい順 / 評価高い順 / 読了日新しい順）。
* **詳細表示・記録編集モーダル:**
  * 本棚の書籍カードをクリックするとモーダルが開く。
  * 編集可能項目：
    * ステータス変更（積読 / 読書中 / 読了）
    * 5段階評価（1〜5の星評価）
    * 読了日（日付入力フォーム）
    * 感想・メモ（テキストエリア）
  * 書籍の削除機能（誤操作防止の確認ダイアログ付き）。

### 2.3 オリジナル・差別化機能
* **「次に読む1冊」ランダム提案機能:**
  * ステータスが「積読」の書籍の中からランダムで1冊を抽出し、モーダル等で大きく提案するボタンを設置する。
  * 積読が0件の場合は「積読リストに本がありません」と案内を表示する。
* **読書統計サマリー表示:**
  * 画面上部に以下の数値をコンパクトに表示する。
    * 今月の読了冊数
    * 累計読了冊数
    * 現在の積読冊数

## 3. データ設計（保存データ構造）

`localStorage`（キー名例: `my_bookshelf_data`）に以下のオブジェクト配列をJSON形式で保存する。

```json
[
  {
    "id": "GoogleBooksのvolumeId（文字列）",
    "title": "書籍タイトル",
    "authors": ["著者名1", "著者名2"],
    "publishedDate": "2024-05-01",
    "description": "書籍の概要文",
    "thumbnail": "表紙画像URL（存在しない場合は空文字）",
    "status": "tsundoku", // "tsundoku" | "reading" | "completed"
    "rating": 0,          // 0（未評価）〜 5
    "completedDate": "",  // "YYYY-MM-DD" 形式（未読了時は空文字）
    "memo": "",           // ユーザー入力の感想・メモ
    "addedAt": "2026-11-20T12:00:00.000Z"
  }
]
